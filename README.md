# Playlist Maker

Мобильное приложение для прослушивания музыки и составления плейлистов.

## Технологии и архитектура

**Язык программирования:** Kotlin  
**Архитектура:** MVVM  
**Внедрение зависимостей:** Koin  

**Ключевые библиотеки и инструменты:**
- **Retrofit** — для работы с REST API (интеграция с iTunes Search API);
- **Coroutines** — асинхронная обработка запросов и операций с данными;
- **Room** — локальное хранение избранных треков и плейлистов;
- **Flow** — реактивное обновление интерфейса при изменении данных;
- **MediaPlayer** — воспроизведение аудио;
- **SharedPreferences** — сохранение настроек и офлайн‑данных;
- **ViewBinding** — работа с UI без вызова `findViewById()`;
- **Navigation Component** (NavController, Navigation Graph) — навигация между экранами;
- **TabLayout + ViewPager2 + TabMediator** — переключение между «Избранным» и «Плейлистами»;
- **BottomSheetDialog** — контекстные действия (добавить трек в плейлист, поделиться, удалить);
- **PickMedia** — выбор обложки плейлиста из галереи;
- **AppCompatDelegate** — смена темы оформления (светлая/тёмная).

**UI‑инструменты:**
- XML (разметка);
- BottomNavigationView (нижняя панель навигации);
- LinearLayoutManager и GridLayoutManager (списки и сетки);
- кастомные Adapter с паттерном ViewHolder.

**Дополнительно:**
- поддержка разных разрешений экранов;
- локализация (RU/EN);
- Intent — функционал шаринга приложения и плейлистов.

## Использование

### Основные функции

- **Поиск треков** через iTunes Search API.
- **Офлайн‑доступ** к последним найденным трекам (сохраняются в `SharedPreferences` в формате JSON).
- **Воспроизведение аудио** с помощью `MediaPlayer`.

#### Избранное

- добавление/удаление треков;
- офлайн‑доступ;
- реактивное обновление интерфейса через `Flow`.

#### Плейлисты

- создание и удаление плейлистов;
- установка обложки (выбор из галереи через `PickMedia`);
- наполнение плейлистов треками;
- офлайн‑доступ к плейлистам и трекам;
- реактивное обновление интерфейса через `Flow`.

#### Шаринг

- приложения;
- отдельных плейлистов (через `Intent`).

#### Тема оформления

- светлая/тёмная тема;
- сохранение выбранной темы в `SharedPreferences`.

#### Навигация

- нижняя панель (`BottomNavigationView`) с 3 разделами;
- вкладки со свайпами (`TabLayout` + `ViewPager2`) на главном экране библиотеки.

### Примеры сценариев

**Сценарий 1: поиск и прослушивание трека**

1. Введите название трека или исполнителя в поисковой строке.
2. Выберите трек из результатов поиска.
3. Нажмите на кнопку воспроизведения.

**Сценарий 2: создание плейлиста**

1. Перейдите в раздел «Плейлисты».
2. Нажмите кнопку «Создать плейлист».
3. Введите название и выберите обложку из галереи.
4. Добавьте треки из поиска или избранного.

**Сценарий 3: смена темы**

1. Откройте меню настроек.
2. Выберите светлую или тёмную тему.
