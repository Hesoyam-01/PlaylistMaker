# Playlist Maker

Мобильное приложение для прослушивания музыки и составления плейлистов.

## Технологии и архитектура

**Язык программирования:** Kotlin  
**Архитектура:** MVVM  
**Внедрение зависимостей:** Koin  

**Ключевые библиотеки и инструменты:**
- **Retrofit** — для работы с REST API (интеграция с iTunes Search API);
- **Coroutines** — асинхронная обработка запросов и операций с данными;
- **Room** — локальное хранение избранных треков и плейлистов;
- **Flow** — реактивное обновление интерфейса при изменении данных;
- **MediaPlayer** — воспроизведение аудио;
- **SharedPreferences** — сохранение настроек и офлайн‑данных;
- **ViewBinding** — работа с UI без вызова `findViewById()`;
- **Navigation Component** (NavController, Navigation Graph) — навигация между экранами;
- **TabLayout + ViewPager2 + TabMediator** — переключение между «Избранным» и «Плейлистами»;
- **BottomSheetDialog** — контекстные действия (добавить трек в плейлист, поделиться, удалить);
- **PickMedia** — выбор обложки плейлиста из галереи;
- **AppCompatDelegate** — смена темы оформления (светлая/тёмная).

**UI‑инструменты:**
- XML (разметка);
- BottomNavigationView (нижняя панель навигации);
- LinearLayoutManager и GridLayoutManager (списки и сетки);
- кастомные Adapter с паттерном ViewHolder.

**Дополнительно:**
- поддержка разных разрешений экранов;
- локализация (RU/EN);
- Intent — функционал шаринга приложения и плейлистов.
